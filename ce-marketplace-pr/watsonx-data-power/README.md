# IBM Power — watsonx.data: Zero-ETL Data Federation on IBM Power

A pre-sales platform reality demo demonstrating zero-ETL data federation across IBM i (core ERP on Db2 for i), PostgreSQL on RHEL on IBM Power, and live streaming event feeds via IBM watsonx.data. Reacts to synthetic cyber security and logistics supply-chain disruption signals in sub-second response times, surfaced through a Carbon Design System dashboard running on IBM Power hardware.
