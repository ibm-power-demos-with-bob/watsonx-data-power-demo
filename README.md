# watsonx.data on IBM Power — Zero-ETL Data Federation Demo

A platform-reality demo for watsonx.data on IBM Power where a live supply-chain disruption — a tier-2 supplier cyber breach or a freight corridor closure — hits a federated query that spans IBM i Db2, PostgreSQL on RHEL/Power, and a streaming event channel, all without moving a byte of data. Bob story-tailors the scenario to your customer, then drives automated deployment across three TechZone environments (IBM i + RHEL, IBM Cloud Satellite, watsonx.data Dev Image), loading 100k-row datasets, wiring federation connectors via Satellite, and starting a Carbon Design System dashboard on RHEL — the audience sees `erp_visibility = 'NOT VISIBLE IN ERP WITHOUT FEDERATION'` in a live Presto query result.
